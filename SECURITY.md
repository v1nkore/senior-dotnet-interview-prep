# Security and privacy

Этот репозиторий публичный. Не добавляйте в него:

- токены, cookies, пароли и connection strings с реальными учётными данными;
- `appsettings.Local.json`, `.env` и локальные профили запуска;
- резюме, контакты, идентификаторы аккаунтов и сопроводительные письма;
- production-логи и дампы баз данных.

Для примеров используйте фиктивные значения и файлы `*.example`. Если секрет попал в историю, одного удаления файла недостаточно: секрет нужно немедленно отозвать и очистить историю репозитория.
