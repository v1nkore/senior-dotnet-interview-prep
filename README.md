# Senior .NET Interview Prep

Единый публичный репозиторий для подготовки к Senior .NET backend-интервью: учебные проекты, алгоритмы, system design, актуальный план и материалы для пробных собеседований.

## Структура

- `docs/` — план подготовки, карта покрытия и служебный банк интервью.
- `projects/` — практические .NET-проекты: runtime, ASP.NET Core, EF Core, Kafka, Redis, gRPC, тестирование, производительность, наблюдаемость и Kubernetes.
- `algorithms/` — задачи на структуры данных и алгоритмы на C#.
- `archive/` — прежние материалы, сохранённые только как история; они не являются текущей программой.

## Как работать

1. Изучить тему через соответствующий проект.
2. Запустить код и тесты самостоятельно.
3. Объяснить решения своими словами без конспекта.
4. Пройти слепое интервью: вопросы заранее не просматриваются.
5. Вернуть слабые темы через 1, 3 и 7 дней.

Текущая программа ориентируется на .NET 10, C# 14, EF Core 10 и типичный стек Senior backend-вакансий: PostgreSQL, Kafka/RabbitMQ, Redis, Docker/Kubernetes, CI/CD и observability.

## Проверка

```bash
dotnet restore projects/PetProjects.sln
dotnet build projects/PetProjects.sln --configuration Release --no-restore
dotnet test projects/PetProjects.sln --configuration Release --no-build
```

Часть интеграционных сценариев требует Docker; требования указаны в README конкретного проекта.

## Приватность

Резюме, контакты, сопроводительные письма, идентификаторы аккаунтов, локальные настройки и токены намеренно исключены. Репозиторий рассчитан на публичный доступ.
