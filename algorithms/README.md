# Algorithms practice

Небольшие задачи на C# для отработки коллекций, граничных случаев и оценки сложности.

Каждая папка содержит отдельный консольный проект. При разборе задачи нужно:

1. Сначала проговорить ограничения и примеры.
2. Назвать сложность по времени и памяти.
3. Написать решение без подсказки.
4. Проверить пустой ввод, один элемент, дубликаты и крайние значения.
5. Объяснить альтернативное решение и его компромиссы.

Сборка всех задач:

```bash
dotnet build LeetCode.Practice.slnx
```
