# Архив прежних материалов

Здесь сохранены предыдущие конспекты и маршрут подготовки, чтобы не терять историю. Они не являются текущей программой и могут содержать устаревшие формулировки.

- `200-answers-senior-dotnet.html` — прежний справочник из 200 ответов.
- `previous-roadmap.md` — предыдущий чек-лист и карта проектов.
- `previous-readme.md` — описание старой структуры отдельных репозиториев.

Тест со 100 вариантами ответа намеренно удалён: длина ответа позволяла угадывать правильный вариант, поэтому результат не измерял знания.

Актуальные материалы находятся в `../../docs/`.
